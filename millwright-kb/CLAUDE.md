# Millwright KB: working notes for Claude

Knowledge-base app for millwright students and teachers. Vite + React + TypeScript front end,
Supabase back end (all objects prefixed `mw_`), content as markdown under `content/`, deployed to
Cloudflare Workers by `.github/workflows/millwright-kb.yml` on every push.

## Rules for content

1. **Every article ships with at least one visual aid.** A procedure, chart or how-to without a
   figure is not finished. `scripts/build-seed.mjs` (run by CI) fails when an article has no
   `![alt](/img/...)` reference or references an image that does not exist.
2. Diagrams are SVG generated by code, not hand-drawn files: add a `fig(...)` call to the matching
   module in `scripts/diagrams/` (one module per subject area) using the helpers in
   `scripts/diagrams/lib.mjs` (`svg`, `box`, `callout`, `legend`, `dim`, `angle`, `chart`, `table`,
   `caption`). Run `node scripts/diagrams/run.mjs [module]` to regenerate into `public/img/`.
   The generator prints an overflow warning for any text that runs outside the canvas: fix every one.
3. Place figures with `scripts/figures.json` (`slug` -> list of `{img, alt, after}` where `after` is a
   `## Heading` in the article or `"top"`) and run `node scripts/add-figures.mjs`; it is idempotent.
4. Author diagrams at 500 px wide with 10-13 px text so they stay legible on a phone; captions
   under about 70 characters; keep numbers in the diagram consistent with the article text.
5. Article style: imperial first with metric alongside, US OSHA/AWS practice with Red Seal/CSA notes
   where they differ, every chart cites its `source:` in the front matter, and every article ends with
   `## Related` links as `/article/<slug>`. Front matter strings must not contain unescaped `"`.
6. To check a diagram visually, render it through headless Chromium (Playwright is preinstalled in
   the sandbox) and look at the PNG before shipping it.

## Pipeline for a content change

```
node scripts/diagrams/run.mjs            # regenerate SVGs (fix any overflow warnings)
node scripts/add-figures.mjs             # place figures from scripts/figures.json
node scripts/build-seed.mjs              # validates front matter, categories, slugs and figures
SEED_TOKEN=... node scripts/seed.mjs     # push to the live database (or --out payload.json + curl)
```

Commit `content/`, `public/img/`, `scripts/` and `supabase/seed/` together.
